# Taió Plumbing System — Seção 2D interativa

Mapa em planta + seção transversal interativa (Plotly, HTML autônomo, roda
offline sem servidor) do sistema intrusivo de Taió — sill/soleira e dique de
diabásio intrudindo formações sedimentares da Bacia do Paraná.

Abra `secao_interativa.html` direto no navegador.

Complemento do modelo 3D: [taio-plumbing-system-3d](https://github.com/Thubaraleii/taio-plumbing-system-3d).

Gerado por `gerar_secao_interativa.py` (Python, Plotly) — o script depende
dos dados do projeto completo (topografia, polígonos de campo, litologia
CPRM) e não roda de forma standalone fora dessa estrutura; está incluído
aqui só como referência/histórico do código.
